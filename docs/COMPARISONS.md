# Molt comparisons (generated)

Illustrative model fixtures, not empirical security benchmarks.

Generated by `pubky_molt::comparisons::render_comparisons` from `fixtures/baselines/*.json` \
and `fixtures/declared/*.json`, and pinned by the crate-level doc test. Do not edit by hand; \
regenerate with `MOLT_COMPARISONS_REGENERATE=1 cargo test --doc` and commit the result.

Method: each comparison scores a manifest-only **baseline** fixture (never executed) and a \
**Molt route** produced by the bounded planner from declared adapters, under the baseline's own \
recorded assumption set. Scoring constants (recorded in `tests/vectors/molt_route_v1.json`): \
confidence weights Exact=1.0, High=0.8, Statistical=0.3; colluding-set weight `w(|S|)=1/|S|`; \
detach bonus None=0, Unknown=0.1, Independent=1.0, CollusionBounded(k)=1.0+0.5k; \
severity ROOT_IDENTITY=100 ≫ RELATIONSHIP_IDENTITY=25 ≫ PAIRWISE_KEY=20 ≫ identifiers=10 > \
AMOUNT/TIME=5 > RELATIONSHIP_LINK=2 > other=1. Weights preset: PRIVATE \
(continuity=0.7, cost=0.2, latency=0.1). None of the detach levels below claims resistance \
to a global passive observer.
